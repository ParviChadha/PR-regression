# Pull request #5810: Skip the indentation after a newline 8 bytes at a time

## Description
Stacked on #5809, which derives the lexer position lazily for seekable input. Only the top commit belongs to this PR.

## What

Pretty-printed JSON indents every line with a run of spaces, and `skip_whitespace()` read them one character at a time. For contiguous input (`bulk_scan`: pointers, `std::string`, `std::vector<char>` and similar), the lexer now skips the spaces after a newline in 8-byte steps, directly in the input buffer. `lexer::skip_indentation()` loads 8 bytes, XORs them with `0x2020…20` and skips whole words of spaces. On the first word that is not all spaces, it also skips that word's leading spaces using a count of trailing zeros. Tabs, `\r`, the last 7 bytes of the input and anything that is not a space go through the existing byte loop.

The skip bypasses `get()`. That is safe because `bulk_scan` implies `lazy_position` from #5809: the position comes from the adapter, so nothing has to be counted per character. Streams, files, wide strings and user-defined adapters are unchanged.

The idea comes from Glaze's `skip_matching_ws`, which compares against the previous line's indentation. Comparing against spaces is simpler (no state) and handles any indent width.

Changes:
- `detail/input/lexer.hpp`: adds `skip_indentation()`, called after `'\n'` in `skip_whitespace()`.
- `detail/bit_ops.hpp`: adds `count_trailing_zeros()`, using `__builtin_ctzll` or a portable fallback (the fallback was checked against the builtin for 640k values).
- `docs/home/architecture.md`: one sentence about the bulk-scan interface.

## Performance
