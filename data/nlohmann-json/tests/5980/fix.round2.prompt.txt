# Pull request #5980: MessagePack reader: read runs of scalar array elements in one loop

## Description
Stacked on #5976.

## What

This is the MessagePack counterpart of #5975. When an array opens and the input is contiguous, the reader reads the integers, floats, booleans and nils that follow in one tight loop (`parse_msgpack_scalar_run`). The loop switches on the head byte, loads the big-endian value straight from the input buffer and calls the SAX handler, instead of taking one trip through `parse_msgpack_internal` and `parse_msgpack_value` per element.

- Covered: positive and negative fixint, uint 8/16/32/64, int 8/16/32/64, float 32/64, nil, false and true.
- The loop stops at any other value and when fewer than 9 bytes are left. Those values go through the existing path, which reads them exactly as before.
- It runs once, when an array (fixarray, array 16, array 32) opens. As in #5975, a per-element check was not worth its cost.
- Non-contiguous inputs are unaffected (tag dispatch on the bulk-scan capability).
