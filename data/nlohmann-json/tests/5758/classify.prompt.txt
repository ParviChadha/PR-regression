# Pull request #5758: Add with_*_t alias templates to create basic_json types with changed template parameters

## Description
Adds member alias templates to `basic_json` that create a `basic_json` type with one of its template parameters replaced, so you don't have to spell out all eleven:

```cpp
using my_json = nlohmann::json::with_string_t<my_string>;
// instead of
using my_json = nlohmann::basic_json<std::map, std::vector, my_string, bool, std::int64_t, std::uint64_t,
                                     double, std::allocator, nlohmann::adl_serializer, std::vector<std::uint8_t>>;
```

Aliases: `with_object_t`, `with_array_t`, `with_string_t`, `with_boolean_t`, `with_integers_t<I, U>`, `with_float_t`, `with_allocator_t`, `with_json_serializer_t`, `with_binary_t`, `with_base_class_t`. Together they cover all template parameters. They are members, so they also work from `ordered_json` or any other specialization and keep its other parameters.

This takes over #3898 by @barcode, which went stale. Their commit is included with them as author. On top of it, following the review in #3898:

- `with_changed_*_t` is renamed to the shorter `with_*_t`.
- The separate signed and unsigned integer aliases are merged into `with_integers_t<I, U>` (@gregmarr's suggestion), because the two are usually changed together.
- New documentation page `api/basic_json/with_t.md` with an example, linked from the `basic_json` index and `mkdocs.yml`.
- `std::is_same` tests for every alias in `unit-udt.cpp`, including one that checks `ordered_json::with_string_t` keeps `ordered_map`.
- Tests and examples that spelled out the full parameter list now use the aliases.

Supersedes #3898. Thanks @barcode!

## Public API

Only additions: ten new public member alias templates on `basic_json`. Nothing existing changes. No breaking changes.
