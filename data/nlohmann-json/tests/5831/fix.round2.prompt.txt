- Output must be deterministic. Never print pointers or addresses, uninitialized data, the order of

  boundaries, special values, nesting, unusual types) and also neighbouring behavior the change could disturb.

  conversions), test it with the detection idiom (std::void_t or requires) and `if constexpr`, so the program

  program. Reach it through the public API that depends on it, using detection (as above) where needed.
- Use the exact types and values the diff is about (the new trait's argument types, the new overload's

# Pull request #5831: Look up the key only once in the callback parser's key()

## Description
## Summary

Since #5466, `json_sax_dom_callback_parser::key()` searched the object for a duplicate key with `find()` and then looked the key up a second time with `operator[]` to insert the placeholder. That doubled the tree lookups per member and made `json::parse(s, callback)` on one very wide object slower than in 3.12.0. This replaces both lookups by a single `emplace()`; duplicate-key semantics (stash and restore) are unchanged.

Callback parse of `{"k0":0,…,"k31999":31999}` (Apple M1 Max, clang, -O3, median of 31, interleaved, machine under load):

| | 3.12.0 | develop | this PR |
|---|---|---|---|
| 8k members | 1.9 ms | 2.4 ms | 1.7 ms |
| 32k members | 8.3 ms | 10.5 ms | 7.2–8.1 ms |
| 128k members | 35 ms | 45 ms | 31 ms |

Comparing #5466 with its parent at 32k members: 7.3 ms vs 10.4 ms. Plain parsing is unchanged.

Tests: `unit-class_parser`, `unit-diagnostic-positions`, `unit-regression2` pass.
