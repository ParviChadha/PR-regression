# Pull request #5964: Write integers of 17 to 20 digits eight digits at a time in dump()

## Description
#5634 made `dump()` write integers below 10^16 eight digits at a time; larger ones still took the two-digits-per-division loop and `count_digits()`. Random 64-bit integers almost all have 17 to 20 digits (99.9 % of `signed_ints.json` and `unsigned_ints.json`), so `Dump/signed_ints` and `Dump/unsigned_ints` gained only 1.4× over 3.12.0, against 2.3× for small integers.

## Change

A 64-bit magnitude with 17 to 20 digits is now written as its first one to four digits and two groups of eight, with the same `eight_digit_bytes()`/`store_msb_first()` helpers as the 16-digit path.

- Wider magnitudes (`__int128` and class types, #5805) keep the loop. Number types of at most 64 bits are selected by type, so no compiler reports the comparison as always true. Other types compare the value.
- The sign handling of #1447/#5815 (`remove_sign()` into `number_magnitude_t`) is unchanged.
- New test: every digit count from 1 to 20 (powers of ten, ±1, all 9s), the int64/uint64 limits, and 20,000 pseudo-random values of every bit length, signed and unsigned, compared with `std::to_string`.

## Measurements

A/B harness: both versions in one binary, alternating samples, six code layouts. Each value is `dump()` of the whole document, B/A, where < 1 is faster.

TEST_CASE("serializer buffers are flushed mid-string and mid-binary")
{
    SECTION("a long run of escaped characters")
    {
        // each character is escaped on its own, so the escape buffer fills up
        const json newlines = std::string(600, '\n');
        std::string expected = "\"";
        for (int i = 0; i < 600; ++i)
        {
            expected += "\\n";
        }
        expected += '"';
        CHECK(newlines.dump() == expected);

        // every character is \u-escaped under ensure_ascii
        std::string umlauts;
        std::string escaped_umlauts = "\"";
        for (int i = 0; i < 300; ++i)
        {
            umlauts += "\xC3\xA4";
            escaped_umlauts += "\\u00e4";
        }
        escaped_umlauts += '"';
        CHECK(json(umlauts).dump(-1, ' ', true) == escaped_umlauts);
    }

    SECTION("a large binary value")
    {
        std::vector<std::uint8_t> bytes(3000);
        std::string expected_bytes;
        std::string expected_pretty_bytes;
        for (std::size_t i = 0; i < bytes.size(); ++i)
        {
            bytes[i] = static_cast<std::uint8_t>(i % 256);
            expected_bytes += (i == 0 ? "" : ",") + std::to_string(i % 256);
            expected_pretty_bytes += (i == 0 ? "" : ", ") + std::to_string(i % 256);
        }
        const json j = json::binary(bytes);
        CHECK(j.dump() == "{\"bytes\":[" + expected_bytes + "],\"subtype\":null}");
        CHECK(j.dump(2) == "{\n  \"bytes\": [" + expected_pretty_bytes + "],\n  \"subtype\": null\n}");
    }
}
