# Pull request #5966: Fix the red CI on develop: remove the duplicate is_editable in basic_json_view

## Description
## Problem

develop has been red since #5890 merged. #5919 replaced the `bool Editable` template parameter of `basic_json_view` by `view_mode Mode` and defines `is_editable` from `Mode`. #5890 was written before that and added a second `static constexpr bool is_editable = Editable;` to the private section. Together they do not compile ("duplicate member `is_editable`", "undeclared identifier `Editable`"), so every job that builds the json_view tests fails: macOS (`macos-15`, `macos-26`, `xcode_standards`), Windows (MSVC, clang-cl, clang, `ci_module_cpp20`) and the CodeQL build. The `source()` errors in `unit-json_view.cpp` in those logs are follow-on errors from the broken class.

## Change

Remove the duplicate member and its comment from `include/nlohmann/json_view.hpp` and regenerate `single_include/nlohmann/json_view.hpp` (`make amalgamate`). Nothing else changes.

## Testing

`unit-json_view` and `unit-json_view_compare` build with clang++ (C++11) and pass locally.

## Breaking changes

No breaking changes: the removed member was private and did not compile.
