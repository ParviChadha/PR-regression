# Pull request #5975: CBOR reader: read runs of scalar array elements in one loop

## Description
## What

When a definite-length CBOR array opens and the input is contiguous, the reader now reads the integers, floats, booleans and nulls that follow in one tight loop (`parse_cbor_scalar_run`). It switches on the head byte, loads the big-endian value straight from the input buffer and calls the SAX handler. Elements no longer go one by one through `parse_cbor_internal`'s container bookkeeping and `parse_cbor_value`'s dispatch.

- The loop stops at any other kind of value (strings, containers, tags, half floats, simple values) and when fewer than 9 bytes are left. Those values go through the existing path, which reads them exactly as before, so positions, errors and SAX events do not change.
- It runs only once, when the array opens. A check in the main loop, run for every element, cost +3 % on citm_catalog, whose arrays mix scalars and objects.
- Non-contiguous inputs (streams, `std::list` iterators) are not affected. Tag dispatch on the bulk-scan capability means they never instantiate the bulk calls.
- `number_float` now receives a member empty `string_t` as its source, instead of a `std::string` constructed for every float.

This is the CBOR part of the binary-format research (see #5968 for the BSON part).

## Measurements

Instructions and time per parse, B/A (A = develop 755bb16d7a), from the ab-harness one-binary A/B (both layouts). The Mac is an M1 Max with Apple clang (instructions retired, 60 reps); GCC 13 is x86-64 under callgrind.

## Tests

New test case "CBOR arrays of scalars from contiguous and non-contiguous input" in `unit-cbor.cpp`. It reads a document containing every scalar head the loop handles, among them the 1/2/4/8-byte integers, −2^64 as a float, int64 min, half/single/double floats, booleans and null. It checks values and then, for every truncation of the document, compares contiguous against non-contiguous input:
- the result or error of `from_cbor`,
- the full SAX event log,
- a SAX handler that stops after each of the first 60 events.

The full ctest suite passes with ASan/UBSan (184/184).
