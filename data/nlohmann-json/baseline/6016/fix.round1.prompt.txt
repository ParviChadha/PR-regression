Rules for every program:

  enough to make differences visible, one fact per line.

## Description
## Summary

develop fails to build in two places since this afternoon's merges. Every PR's CI is red because of it, since CI builds each PR merged with develop.

**MSVC C4127 (all MSVC and clang-cl jobs, `ci_module_cpp20`).** #6006 folded the check for a digit after a minus sign in `json_view`'s `number()` into `else if (!negative || ...)`. MSVC 19.44 reports that as "conditional expression is constant", and `/WX` makes it an error:

```
include\nlohmann\detail\view\builder.hpp(1177,32): warning C4127: conditional expression is constant
```

The check now sits in the `if (negative)` block, right after the sign is skipped. Numbers without a sign take exactly the same path as before. The error code (`number_after_minus`) and the position it reports are unchanged.

**GCC `-Weffc++` (`ci_test_gcc`, the GCC compiler matrix, static analysis).** `locale_switching_token` in `unit-locale-cpp.cpp` (from #5997) held a `const char*`, so GCC asked for a copy constructor and copy assignment:

```
tests/src/unit-locale-cpp.cpp:504:8: error: 'struct {anonymous}::locale_switching_token' has pointer data members [-Werror=effc++]
```

The locale name is now a `std::string`, so no copy members need adding.

The third failure on develop's last finished run (`unit-json_view_positions.cpp:573`, a removed value with a byte range in its exception) is already fixed by #6015.

## Testing

- GCC 16 (Docker), `-Werror -Weffc++`: reproduces the three errors on develop and is clean with this change.
- MSVC 19.44 (the CI version) on Compiler Explorer, `/W4 /WX` and `/permissive- /std:c++latest /W4 /WX`: the old pattern triggers C4127, the new one compiles cleanly. This used a reduced copy of `number()`, not the whole header.
- Locally (clang, macOS): `unit-json_view`, `unit-json_view_builder`, `unit-json_view_positions`, `unit-json_view_large`, `unit-locale-cpp` and `unit-class_lexer` pass.

## Breaking changes

No breaking changes. Behaviour and the public API are unchanged; one test helper changes.
